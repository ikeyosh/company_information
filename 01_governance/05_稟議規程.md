# 稟議(りんぎ)規程

**制定日**: 2024年4月1日
**最終改定**: 2025年4月1日
**管理部門**: 総務部・経営企画室

---

## 第1章 総則

### 第1条(目的)
本規程は、株式会社サンプルテクノロジー(以下「当社」という)における稟議制度の適正な運用を図り、意思決定の迅速化と責任の明確化を目的とする。

### 第2条(適用範囲)
1. 本規程は、当社の全役員及び全従業員に適用する。
2. 稟議を要する事項は、職務権限規程に定めるところによる。

### 第3条(稟議の定義)
稟議とは、業務の執行にあたり、所定の事項について起案者が稟議書を作成し、関係部門及び上位者の承認を経て、決裁権者の決裁を受ける一連の手続きをいう。

### 第4条(基本原則)
1. 稟議は、事前承認を原則とする。
2. 稟議書は、事実を正確に記載し、虚偽の記載をしてはならない。
3. 稟議の承認・決裁は、職務権限規程に基づいて行う。
4. 稟議は、電子稟議システムを使用して行うことを原則とする。

---

## 第2章 稟議事項

### 第5条(稟議を要する事項)
次の各号に掲げる事項については、稟議書による承認を得なければならない。

**【経営関連】**
1. 中期経営計画、年度事業計画及び予算に関する事項
2. 組織の新設、変更、統廃合に関する事項
3. 重要な社内規程の制定、改廃に関する事項

**【人事関連】**
4. 役員、管理職の任免に関する事項
5. 従業員の採用、異動、昇格、降格に関する事項
6. 懲戒処分に関する事項
7. 賃金、賞与、退職金の決定及び変更に関する事項
8. 人員計画に関する事項

**【財務・経理関連】**
9. 年度決算、中間決算に関する事項
10. 借入金、社債の発行に関する事項
11. 固定資産の取得、処分に関する事項
12. 投資、出資に関する事項
13. 債権の放棄、免除に関する事項

**【営業関連】**
14. 重要な契約の締結、変更、解除に関する事項
15. 価格の決定、値引き、割引に関する事項
16. 与信限度額の設定、変更に関する事項
17. 新規取引先との取引開始に関する事項

**【購買・調達関連】**
18. 一定金額以上の物品購入に関する事項
19. サプライヤーの選定に関する事項
20. 購買契約の締結に関する事項

**【総務・法務関連】**
21. 訴訟の提起、応訴、和解に関する事項
22. 重要な契約書の締結に関する事項
23. 社印、代表印の使用に関する事項

**【その他】**
24. 一定金額以上の経費支出に関する事項
25. その他、取締役会、社長が稟議を要すると認める事項

### 第6条(稟議を要しない事項)
次の各号に掲げる事項については、稟議を要しない。
1. 日常的な定型業務
2. あらかじめ承認された予算の範囲内での少額の支出(10万円未満)
3. 緊急を要する事項で口頭承認を得たもの(ただし、事後稟議を要する)

---

## 第3章 稟議書の作成と提出

### 第7条(稟議書の作成)
1. 稟議を要する事項が発生したときは、起案者は速やかに稟議書を作成する。
2. 稟議書は、電子稟議システムを使用して作成することを原則とする。
3. やむを得ない事情により紙で作成する場合は、所定の様式(別紙様式1)を使用する。

### 第8条(稟議書の記載事項)
稟議書には、次の事項を明確に記載する。
1. 件名(簡潔かつ具体的に)
2. 起案日
3. 起案部署及び起案者
4. 稟議事項の内容
   - 背景・目的
   - 具体的な内容
   - 必要性・効果
   - リスク・課題
5. 金額(該当する場合)
6. 予算科目及び予算残高
7. 実施時期
8. 添付資料(見積書、契約書案、比較表等)
9. 関係部門の意見(必要に応じて)
10. 承認ルート(承認者・決裁者)

### 第9条(稟議書作成の注意事項)
起案者は、稟議書作成にあたり、次の事項に留意する。
1. 5W2H(誰が、何を、いつ、どこで、なぜ、どのように、いくら)を明確にする
2. 客観的な事実とデータに基づいて記載する
3. 複数の選択肢がある場合は、比較検討を行い、推奨案とその理由を明記する
4. 添付資料を適切に添付する(見積書、契約書案、稟議根拠資料等)
5. 誤字脱字がないか確認する

### 第10条(添付書類)
稟議書には、案件の内容に応じて、次の書類を添付する。
1. 見積書(相見積もりを原則とする)
2. 契約書案
3. 比較検討表
4. 予算対比表
5. 費用対効果分析資料
6. リスク評価資料
7. その他、必要と認める資料

---

## 第4章 稟議の承認ルート

### 第11条(承認ルート)
1. 稟議の承認ルートは、起案部署及び稟議事項の内容・金額に応じて、職務権限規程に基づき設定する。
2. 標準的な承認ルートは、次のとおりとする。

```
起案者 → 直属上司(係長) → 課長 → 次長 → 部長 → 本部長 →
担当役員(副社長/専務/常務) → 社長 → (取締役会)
```

3. 金額・内容により、途中の承認者を省略することができる。

### 第12条(承認ルートの設定基準)

| 稟議金額 | 承認ルート |
|---|---|
| 10万円未満 | 起案者 → 課長 |
| 10万~100万円 | 起案者 → 課長 → 部長 |
| 100万~1,000万円 | 起案者 → 課長 → 部長 → 本部長 |
| 1,000万~5,000万円 | 起案者 → 課長 → 部長 → 本部長 → 担当役員 |
| 5,000万~1億円 | 起案者 → 課長 → 部長 → 本部長 → 担当役員 → 社長 |
| 1億円以上 | 起案者 → 課長 → 部長 → 本部長 → 担当役員 → 社長 → 取締役会 |

### 第13条(関係部門の合議)
次の事項については、関係部門の合議(事前承認)を必要とする。
1. 契約締結 → 法務部の合議
2. 一定額以上の支出 → 経理部の合議
3. システム導入 → 情報システム部の合議
4. 人事関連 → 人事部の合議
5. その他、必要と認める部門

### 第14条(合議の方法)
1. 合議が必要な稟議については、起案者は関係部門に合議依頼を行う。
2. 合議部門は、稟議書の内容を確認し、問題がなければ承認する。
3. 合議部門が修正を求める場合は、起案者と協議の上、内容を修正する。

---

## 第5章 稟議の承認・決裁

### 第15条(承認者・決裁者の責務)
1. 承認者及び決裁者は、稟議書の内容を十分に精査し、適切に判断する。
2. 承認者は、次の観点から稟議書を審査する。
   - 必要性と妥当性
   - 費用対効果
   - リスクとその対策
   - 予算との整合性
   - 法令・社内規程への適合性
   - 添付資料の適切性

### 第16条(承認・却下・差戻し)
承認者及び決裁者は、稟議書の内容に応じて、次のいずれかの処理を行う。
1. 承認: 稟議内容を承認し、次の承認者へ回付する
2. 却下: 稟議内容が不適切と判断した場合、理由を明記して却下する
3. 差戻し: 記載内容が不十分な場合、修正を求めて起案者に差し戻す
4. 保留: 追加の検討や情報収集が必要な場合、一時的に保留する

### 第17条(承認期限)
1. 承認者は、稟議書を受理後、原則として2営業日以内に承認・差戻し等の処理を行う。
2. やむを得ない事情により期限内に処理できない場合は、起案者にその旨を連絡する。
3. 緊急を要する稟議については、同日中又は翌営業日までに処理する。

### 第18条(決裁の確定)
1. 最終決裁権者が承認したとき、稟議は確定する。
2. 取締役会決議事項については、取締役会で承認されたとき、稟議は確定する。

---

## 第6章 緊急稟議・事後稟議

### 第19条(緊急稟議)
1. 緊急を要する事項で、通常の稟議手続きを経ることが困難な場合は、口頭又は電話により上位者の承認を得て実行することができる。
2. 緊急稟議により実行した場合は、実行後速やかに(原則3営業日以内に)稟議書を作成し、事後承認を受けなければならない。

### 第20条(事後稟議)
1. 次の場合は、事後稟議とすることができる。
   - 災害、事故等の緊急事態への対応
   - 口頭承認を得て実行した事項
   - その他、やむを得ない事情がある場合
2. 事後稟議の場合、稟議書には「事後稟議」である旨及びその理由を明記する。

---

## 第7章 稟議の変更・取消

### 第21条(稟議の変更)
1. 決裁後に稟議内容を変更する必要が生じた場合は、変更稟議を起案する。
2. 変更内容が軽微な場合は、原稟議の決裁者の承認を得れば足りる。
3. 変更内容が重大な場合は、新たに稟議を起案する。

### 第22条(稟議の取消)
1. 決裁後に稟議を取り消す必要が生じた場合は、取消稟議を起案する。
2. 取消稟議は、原稟議の決裁者の承認を必要とする。

---

## 第8章 稟議書の管理

### 第23条(稟議書の保管)
1. 承認・決裁された稟議書は、起案部門において適切に保管する。
2. 電子稟議システムで作成された稟議書は、システム上に保管する。
3. 紙の稟議書は、ファイリングして施錠可能な保管庫に保管する。

### 第24条(稟議書の保存期間)
稟議書の保存期間は、次のとおりとする。
1. 重要な稟議(取締役会決議事項等): 永久保存
2. 一般的な稟議: 10年間保存
3. 軽微な稟議: 5年間保存

### 第25条(稟議書の閲覧)
1. 稟議書は、業務上必要な範囲で閲覧することができる。
2. 稟議書の閲覧には、起案部門長又は総務部長の承認を必要とする。

---

## 第9章 電子稟議システム

### 第26条(電子稟議システムの利用)
1. 稟議は、原則として電子稟議システムを使用して行う。
2. 電子稟議システムの利用方法は、別に定める「電子稟議システム操作マニュアル」による。

### 第27条(電子稟議のメリット)
電子稟議システムの利用により、次の効果を図る。
1. 稟議の迅速化(承認スピードの向上)
2. ペーパーレス化(紙の削減)
3. 稟議状況の可視化(現在の承認状況がリアルタイムで確認可能)
4. 検索性の向上(過去の稟議を容易に検索可能)
5. セキュリティの向上(アクセス権限管理)

### 第28条(電子署名)
電子稟議システムで承認・決裁を行う場合は、電子署名により行う。電子署名は、自筆の署名・押印と同等の効力を有する。

---

## 第10章 雑則

### 第29条(稟議に関する教育)
総務部は、稟議制度の適切な運用を図るため、定期的に稟議に関する教育・研修を実施する。

### 第30条(稟議の監査)
内部監査部門は、稟議制度が適切に運用されているか定期的に監査を実施する。

### 第31条(規程の改廃)
本規程の改廃は、取締役会の決議による。

### 第32条(疑義の解釈)
本規程の解釈について疑義が生じたときは、総務部が経営企画室と協議の上、判断する。

---

## 附則

本規程は、2024年4月1日から施行する。

## 別表2: 稟議チェックリスト

起案者は、稟議書提出前に以下の項目をチェックすること。

### 【記載内容チェック】
- [ ] 件名は具体的で分かりやすいか
- [ ] 背景・目的は明確か
- [ ] 5W2Hが明記されているか
- [ ] 金額は正確か
- [ ] 予算科目と予算残高は確認したか
- [ ] 実施時期は明記されているか
- [ ] リスクと対策は記載されているか

### 【添付資料チェック】
- [ ] 見積書は添付されているか(複数社の相見積もり推奨)
- [ ] 契約書案は添付されているか
- [ ] 比較検討表は作成されているか
- [ ] その他必要な資料は揃っているか

### 【承認ルートチェック】
- [ ] 承認ルートは正しく設定されているか
- [ ] 関係部門の合議は完了しているか
- [ ] 金額に応じた承認者が設定されているか

### 【その他チェック】
- [ ] 誤字脱字はないか
- [ ] 数字の桁は正しいか
- [ ] 期限は適切か(緊急の場合はその旨記載)
