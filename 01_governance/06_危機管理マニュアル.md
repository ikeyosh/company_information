# 危機管理マニュアル(BCP: 事業継続計画)

**制定日**: 2024年4月1日
**最終改定**: 2025年4月1日
**管理部門**: 総務部・リスク管理委員会

---

## 第1章 総則

### 第1条(目的)
本マニュアルは、株式会社サンプルテクノロジー(以下「当社」という)が、災害、事故、不祥事等の危機事態に直面した際に、迅速かつ適切な対応を行い、事業の継続及び早期復旧を図ることを目的とする。

### 第2条(適用範囲)
本マニュアルは、当社の全役員及び全従業員に適用する。

### 第3条(基本方針)
危機管理における基本方針は、次のとおりとする。
1. **人命最優先**: 従業員、顧客、取引先等の人命と安全を最優先する
2. **迅速な初動対応**: 危機発生時は、迅速に初動対応を行う
3. **事業継続**: 重要業務を継続し、早期に通常業務へ復旧する
4. **ステークホルダーへの責任**: 顧客、取引先、株主等への責任を果たす
5. **再発防止**: 危機の再発防止策を講じる

### 第4条(危機の定義)
本マニュアルにおける「危機」とは、次の事態をいう。
1. 自然災害(地震、台風、水害、大雪等)
2. 火災・爆発
3. 感染症の大流行(パンデミック)
4. テロ・暴動
5. 情報セキュリティ事故(サイバー攻撃、情報漏洩等)
6. 重大な製品事故・品質問題
7. 労働災害・重大事故
8. 不祥事・コンプライアンス違反
9. 風評被害
10. その他、事業継続に重大な影響を及ぼす事態

## 第2章 危機管理体制

### 第5条(危機管理委員会)
1. 平時における危機管理体制の整備及び訓練を実施するため、危機管理委員会を設置する。
2. 危機管理委員会は、次の者により構成する。
   - 委員長: 管理本部長
   - 副委員長: 総務部長
   - 委員: 各本部長、情報システム部長、人事部長、法務部長

### 第6条(危機対策本部)
1. 危機が発生した場合、代表取締役社長は、直ちに「危機対策本部」を設置する。
2. 危機対策本部は、次の者により構成する。
   - 本部長: 代表取締役社長
   - 副本部長: 取締役副社長、専務取締役
   - 本部員: 各本部長、総務部長、人事部長、広報担当者
3. 危機対策本部は、次の業務を行う。
   - 情報収集と状況把握
   - 初動対応の指示
   - 対策の決定と実行
   - 外部への情報発信
   - 関係機関との連携

### 第7条(危機対策本部の設置場所)
1. 危機対策本部は、原則として本社会議室に設置する。
2. 本社が使用不能な場合は、次の順序で代替拠点に設置する。
   - 第1代替拠点: 大阪支店
   - 第2代替拠点: 名古屋支店
   - 第3代替拠点: データセンター(外部施設)

## 第3章 危機発生時の初動対応

### 第8条(緊急連絡体制)
1. 危機を発見した者は、直ちに上司及び総務部に報告する。
2. 総務部は、直ちに代表取締役社長、管理本部長及び関係役員に報告する。
3. 緊急連絡は、次の手段を用いる。
   - 社内電話
   - 携帯電話(緊急連絡網)
   - 安否確認システム
   - メール・チャット

### 第9条(初動対応の原則)
危機発生時の初動対応は、次の優先順位で行う。
1. **第1優先: 人命救助と安全確保**
   - 負傷者の救護
   - 避難誘導
   - 二次災害の防止
2. **第2優先: 被害拡大の防止**
   - 消火活動
   - 情報システムの緊急停止
   - 顧客データの保護
3. **第3優先: 情報収集と報告**
   - 被害状況の把握
   - 上位者への報告
   - 関係機関への通報
4. **第4優先: 事業継続の判断**
   - 重要業務の継続可否判断
   - 代替手段の検討

### 第10条(報告基準)
次の事態が発生した場合、直ちに代表取締役社長及び総務部に報告する。
1. 人的被害(死亡、重傷)が発生した場合
2. 重大な財産的損害(1億円以上)が発生した場合
3. 顧客に重大な影響を及ぼす事態が発生した場合
4. メディアの取材があった場合
5. 警察・消防・行政機関から連絡があった場合
6. SNS等で炎上する可能性がある事態が発生した場合

## 第4章 危機別対応マニュアル

### 第11条(地震発生時の対応)

**【発生直後(1分以内)】**
- 「地震だ!」と周囲に声をかける
- 机の下に潜り、頭を守る
- 落下物、転倒物から離れる
- エレベーターは使用しない(閉じ込めのリスク)

**【揺れが収まった後(1~5分)】**
- 火の元を確認し、出火していれば初期消火
- 負傷者の確認と応急手当
- 出口の確保(ドアを開ける)
- 余震に注意

**【避難判断(5~10分)】**
- 館内放送・避難指示に従う
- 階段で避難(エレベーター使用禁止)
- 避難場所: 〇〇公園(本社から徒歩5分)

**【安否確認(10分~1時間)】**
- 各部署で人員点呼
- 安否確認システムに回答
- 行方不明者の捜索

**【帰宅判断】**
- 公共交通機関の運行状況を確認
- 徒歩帰宅が可能か判断
- 帰宅困難な場合は社内待機

### 第12条(火災発生時の対応)

**【発見者の行動】**
1. 大声で「火事だ!」と叫ぶ
2. 火災報知器のボタンを押す
3. 119番通報
4. 初期消火(消火器、消火栓)

**【避難】**
- 煙を吸わないよう、姿勢を低くして避難
- ハンカチやタオルで口を覆う
- エレベーター使用禁止
- 避難後は、絶対に建物内に戻らない

**【消火器の使い方】**
1. 安全栓を抜く
2. ホースを火元に向ける
3. レバーを握って放射
4. ほうきで掃くように消火

### 第13条(感染症(パンデミック)発生時の対応)

**【予防対策】**
- 手洗い、うがい、マスク着用の徹底
- 出社前の体温測定
- 発熱者(37.5度以上)は出社禁止
- オフィスの換気(1時間に1回)
- 共用部の消毒

**【在宅勤務への切り替え】**
- 感染拡大状況に応じて、在宅勤務に切り替え
- 在宅勤務が困難な部署は、時差出勤・交代勤務
- WEB会議の積極活用

**【感染者が発生した場合】**
1. 当該社員は自宅待機、医療機関受診
2. 濃厚接触者の特定と自宅待機
3. 該当フロアの消毒
4. 保健所への連絡
5. 従業員への情報共有(個人情報に配慮)

### 第14条(情報セキュリティ事故発生時の対応)

**【情報漏洩が発覚した場合】**
1. 直ちに情報システム部に連絡
2. 原因の特定(不正アクセス、誤送信、紛失等)
3. 被害範囲の特定
4. 二次被害防止策の実施(パスワード変更、システム停止等)
5. 影響を受ける顧客・取引先への連絡
6. 個人情報保護委員会、警察への届出
7. プレスリリース(必要に応じて)

**【サイバー攻撃を受けた場合】**
1. ネットワークから切り離す
2. ログの保全
3. セキュリティベンダーへの連絡
4. 警察への通報
5. 復旧作業

### 第15条(製品事故・品質問題発生時の対応)

**【事故発覚時の対応】**
1. 品質保証部、営業部、法務部への連絡
2. 事故の詳細確認(発生日時、場所、被害状況)
3. 原因の調査
4. 同様の製品の出荷停止
5. 回収の要否判断

**【リコール実施の場合】**
1. 取締役会での決議
2. 行政機関への届出
3. プレスリリース、ホームページでの告知
4. 顧客への個別連絡
5. 回収・交換の実施
6. 再発防止策の実施

### 第16条(不祥事発生時の対応)

**【不祥事の例】**
- 横領、着服
- 不正会計
- ハラスメント
- インサイダー取引
- 贈収賄
- 反社会的勢力との取引

**【対応手順】**
1. 事実関係の調査(第三者委員会の設置も検討)
2. 関係者の処分
3. 再発防止策の策定
4. 取締役会への報告
5. 必要に応じて、プレスリリース、記者会見
6. 監督官庁への報告

## 第5章 事業継続計画(BCP)

### 第17条(重要業務の特定)
事業継続において優先すべき重要業務は、次のとおりとする。
1. 顧客向けシステムの稼働維持
2. 顧客サポート業務
3. 請求・入金管理業務
4. 給与計算業務
5. 資金繰り管理業務

### 第18条(目標復旧時間(RTO))
各重要業務の目標復旧時間は、次のとおりとする。

| 業務 | RTO | 代替手段 |
|---|---|---|
| 顧客向けシステム | 24時間以内 | バックアップサーバーへ切替 |
| 顧客サポート | 即時 | 在宅勤務、携帯電話対応 |
| 請求・入金管理 | 3日以内 | 手作業、バックアップデータ |
| 給与計算 | 給与支払日まで | 外部委託先へ依頼 |
| 資金繰り管理 | 即時 | 財務部長の携帯・自宅PCで対応 |

### 第19条(代替拠点)
本社が使用不能になった場合の代替拠点は、次のとおり。
- 第1代替拠点: 大阪支店(大阪府大阪市北区〇〇1-2-3)
- 第2代替拠点: 名古屋支店(愛知県名古屋市中区△△4-5-6)
- バックアップサーバー: 外部データセンター(東京都江東区◇◇7-8-9)

### 第20条(データバックアップ)
1. 重要データは、毎日バックアップを実施する。
2. バックアップデータは、本社とは異なる場所(外部データセンター)に保管する。
3. バックアップデータからの復旧訓練を年1回実施する。

## 第6章 広報対応

### 第21条(広報の基本方針)
危機発生時の広報は、次の方針で行う。
1. **迅速性**: 正確な情報を迅速に公表する
2. **透明性**: 隠蔽せず、事実を正直に伝える
3. **一元化**: 情報発信窓口を一本化する
4. **一貫性**: 一貫したメッセージを発信する

### 第22条(広報担当)
1. 対外的な情報発信は、広報担当役員が一元的に行う。
2. 広報担当役員は、総務部長、法務部長と連携して対応する。
3. 現場の従業員は、個別にメディア対応してはならない。

### 第23条(プレスリリース)
重大な危機が発生した場合、速やかにプレスリリースを発行する。
プレスリリースには、次の事項を記載する。
1. 事故・事案の概要
2. 発生日時・場所
3. 被害状況
4. 原因(判明している範囲で)
5. 今後の対応
6. 再発防止策
7. お詫びの言葉
8. お問い合わせ窓口

### 第24条(記者会見)
重大な危機の場合、記者会見を実施する。
記者会見には、代表取締役社長が出席し、謝罪と説明を行う。

### 第25条(SNS対応)
1. SNSでの炎上リスクがある場合、SNSを監視する。
2. 誤った情報が拡散されている場合は、公式SNSで訂正情報を発信する。
3. 個別のコメントには、原則として返信しない。

## 別表4: 危機対策本部 設置フロー

```
【危機発生】
    ↓
発見者 → 上司 → 総務部
    ↓
総務部 → 代表取締役社長に報告
    ↓
代表取締役社長が「危機対策本部設置」を判断
    ↓
【危機対策本部 設置】
場所: 本社3階大会議室
    ↓
メンバー召集(緊急連絡網)
    ↓
【第1回対策本部会議】
- 情報共有
- 初動対応の指示
- 役割分担
    ↓
【対応実行】
    ↓
【定期会議】(1日2回程度)
- 進捗報告
- 追加対策の決定
    ↓
【収束】
危機対策本部 解散
    ↓
【事後対応】
- 原因究明
- 再発防止策
- 取締役会への報告
```
