**策定日**: 2025年3月31日

## エグゼクティブサマリー

株式会社サンプルテクノロジーは、創業以来、ITソリューション事業を核として成長を続けてきました。本中期経営計画(2025-2027年度)では、「デジタル変革のリーディングカンパニー」というビジョンの実現に向け、既存事業の深化と新規事業の探索を両輪として、持続的な成長を目指します。

**数値目標(2027年度末)**
- 売上高: 300億円(年平均成長率15%)
- 営業利益: 45億円(営業利益率15%)
- ROE: 15%以上
- 従業員数: 1,000名

- リモートワークの定着

- 生成AI(ChatGPT等)の急速な普及

- 国内IT市場: 約20兆円(年率3-5%成長)

- クラウド市場: 約4兆円(年率15%成長)

**成長領域**

5. DXコンサルティング

**主要競合**

- 中堅SIerとして、大手と差別化されたサービスを提供
- 特定業界(製造業、流通業)での強み
- 柔軟な対応力とスピード感

### 1-2. 内部環境分析(SWOT分析)

#### 強み(Strengths)
1. 特定業界(製造業・流通業)における深い知見
2. 長期的な顧客関係(主要顧客の平均取引期間10年以上)
3. 高い技術力(AWS認定エンジニア50名、情報処理安全確保支援士30名)
4. 柔軟な組織文化(変化への対応力)
5. 財務体質の健全性(自己資本比率50%)

#### 弱み(Weaknesses)
1. ブランド認知度の低さ(大手に比べて)
2. 人材確保の困難さ(採用競争の激化)
3. 大型案件の受注実績の少なさ
4. グローバル展開の遅れ
5. 新技術(AI、量子コンピューティング等)への投資不足

#### 機会(Opportunities)
1. DX需要の急拡大
2. 生成AIの普及によるビジネスチャンス
3. レガシーシステムの刷新需要
4. 中堅企業のIT化ニーズ増加
5. 人材不足を背景とした外部委託の増加

#### 脅威(Threats)
1. 大手SIerとの競争激化
2. オフショア開発企業の台頭
3. 人材獲得競争の激化・人件費高騰
4. 技術革新のスピード(キャッチアップの困難さ)
5. 景気後退リスク

## 第2章 経営ビジョンと基本戦略

### 2-1. 経営ビジョン

```
「デジタル変革のリーディングカンパニー」

お客様のDXパートナーとして、
最先端の技術と深い業界知見を融合し、
ビジネスの変革と価値創造を実現する。
```

### 2-2. 経営理念

1. **顧客第一**: お客様の成功が、私たちの成功
2. **技術革新**: 常に最先端の技術を追求し、価値を創造
3. **人材育成**: 社員の成長が、会社の成長
4. **社会貢献**: テクノロジーを通じて、より良い社会を実現

### 2-3. 基本戦略(3本の柱)

#### 戦略1: 既存事業の深化と拡大
- 主要顧客との関係強化(シェア・オブ・ウォレットの拡大)
- 製造業・流通業における業界No.1ソリューションプロバイダーへ
- ストック型ビジネスの拡大(保守・運用、SaaS)

#### 戦略2: 新規事業の創出
- 生成AI関連ソリューションの開発・提供
- データアナリティクス事業の立ち上げ
- 新規業界(ヘルスケア、金融)への参入

#### 戦略3: 経営基盤の強化
- 人材の採用・育成強化
- DX推進による業務効率化
- 財務体質の強化
- ESG経営の推進

## 第4章 戦略の詳細

### 4-1. 事業戦略

#### 【システム開発事業】
**現状**: 売上120億円(全体の60%)
**目標**: 売上150億円(2027年度)

**施策**
1. 製造業向けMES(製造実行システム)の強化
2. 流通業向けオムニチャネルシステムの開発
3. アジャイル開発体制の構築
4. オフショア開発の活用拡大(ベトナム、フィリピン)

#### 【クラウドサービス事業】
**現状**: 売上40億円(全体の20%)
**目標**: 売上80億円(2027年度) ← 最重点

**施策**
1. クラウド移行支援サービスの強化
   - AWS、Azure、GCPのマルチクラウド対応
   - レガシーシステムのモダナイゼーション
2. 自社SaaSプロダクトの開発
   - 製造業向け生産管理SaaS「〇〇クラウド」
   - 流通業向け在庫管理SaaS「△△クラウド」
3. クラウドネイティブなシステム開発

#### 【保守・運用事業】
**現状**: 売上30億円(全体の15%)
**目標**: 売上45億円(2027年度)

**施策**
1. 24時間365日のサポート体制構築
2. 運用自動化(AIOps)の推進
3. SLAの高度化
4. マネージドサービスの拡充

#### 【コンサルティング事業】
**現状**: 売上10億円(全体の5%)
**目標**: 売上25億円(2027年度) ← 新規注力

**施策**
1. DXコンサルティングチームの設立(30名体制)
2. 業務コンサル + IT実装の一貫支援
3. 生成AI導入支援サービスの開始
4. データアナリティクスコンサルティング

### 4-2. 技術戦略

#### 【重点技術領域】
1. **生成AI**
   - ChatGPT、Claude等のLLM活用
   - 社内業務へのAI導入
   - 顧客向けAIソリューション開発
2. **クラウド**
   - AWS、Azure、GCPの高度活用
   - クラウドネイティブ開発
   - マルチクラウド・ハイブリッドクラウド対応
3. **データアナリティクス**
   - BI(Tableau、Power BI)
   - データウェアハウス(Snowflake、BigQuery)
   - 機械学習・予測分析
4. **サイバーセキュリティ**
   - ゼロトラストアーキテクチャ
   - SIEM、SOC構築支援
   - セキュリティコンサルティング

#### 【技術投資計画】
- 研究開発費: 売上高の5%(年間10-15億円)
- 重点配分: 生成AI(40%)、クラウド(30%)、データ分析(20%)、その他(10%)

### 4-3. 営業戦略

#### 【ターゲット顧客】
**既存顧客(深耕)**
- 製造業: 大手メーカー、部品サプライヤー
- 流通業: 小売チェーン、卸売業

**新規顧客(開拓)**
- ヘルスケア: 病院、製薬会社
- 金融: 地方銀行、信用金庫、保険会社

#### 【営業施策】
1. アカウント営業の強化(主要50社に専任担当配置)
2. パートナー戦略(大手SIer、ベンダーとの協業)
3. Webマーケティング強化(SEO、コンテンツマーケ、ウェビナー)
4. 展示会・セミナーの積極開催(年12回)
