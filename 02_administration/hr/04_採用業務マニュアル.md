# 採用業務マニュアル

**制定日**: 2024年4月1日
**最終改定**: 2025年4月1日
**管理部門**: 人事部

---

## 第1章 採用方針

### 1-1. 採用目的
1. 事業拡大に必要な人材の確保
2. 組織の活性化
3. 多様性の推進

### 1-2. 求める人材像
1. チャレンジ精神旺盛な人
2. チームワークを大切にする人
3. 誠実で責任感のある人
4. 成長意欲の高い人

---

## 第2章 採用計画

### 2-1. 年間採用スケジュール

**【新卒採用】**
| 時期 | 活動内容 |
|---|---|
| 3月 | 会社説明会開始、エントリー受付 |
| 4月~5月 | 一次面接 |
| 6月 | 二次面接、最終面接 |
| 6月末 | 内々定通知 |
| 10月 | 内定式 |
| 翌年4月 | 入社 |

**【中途採用】**
- 通年実施(随時募集)
- 選考期間: 応募~内定まで約1ヶ月

### 2-2. 採用人数目標(2025年度)
- 新卒: 50名
- 中途: 50名
- **合計: 100名**

↓

## 第4章 母集団形成

### 4-1. 採用チャネル

**【新卒採用】**
1. 就職ナビサイト(マイナビ、リクナビ等)
2. 自社ホームページ
3. 会社説明会
4. インターンシップ
5. 大学就職課との連携
6. リファラル採用(社員紹介)

**【中途採用】**
1. 転職サイト(doda、ビズリーチ等)
2. 人材紹介会社
3. 自社ホームページ
4. リファラル採用
5. ダイレクトリクルーティング(LinkedIn等)
6. ハローワーク

### 4-2. 会社説明会
**【開催頻度】**
- 新卒: 3月~5月に月2回実施
- 中途: 隔月1回実施

**【プログラム】**
1. 会社概要説明(15分)
2. 事業内容説明(20分)
3. 社員座談会(20分)
4. 質疑応答(5分)

### 4-3. インターンシップ
**【実施時期】**
- 夏季: 8月~9月(5日間)
- 冬季: 2月(3日間)

**【内容】**
- 職場体験
- プロジェクト型ワーク
- 先輩社員との交流

## 第5章 選考プロセス

### 5-1. 書類選考

**【提出書類】**
- 履歴書
- 職務経歴書(中途のみ)
- エントリーシート(新卒のみ)

**【選考基準】**
1. 学歴・職歴が募集要件を満たしているか
2. 志望動機が明確か
3. 転職回数(中途の場合)
4. 記載内容に不備がないか

**【選考期間】**
- 応募~結果通知: 1週間以内

### 5-2. 適性検査・筆記試験(新卒のみ)

**【実施内容】**
1. SPI3(能力検査・性格検査)
2. 一般常識テスト

**【実施方法】**
- WEBテスト(自宅受検)

### 5-3. 一次面接

**【面接官】**
- 人事部(新卒)
- 人事部+配属先部門長(中途)

**【所要時間】**
- 30分~45分

**【質問例】**
1. 志望動機
2. 自己PR
3. 学生時代(又は前職)で頑張ったこと
4. 入社後にやりたいこと
5. 逆質問

**【評価項目】**
- コミュニケーション能力
- 論理的思考力
- 主体性
- 当社とのマッチ度

### 5-4. 二次面接

**【面接官】**
- 配属先部門長(新卒)
- 役員(中途)

**【所要時間】**
- 45分~1時間

**【評価項目】**
- 専門知識・スキル(中途)
- リーダーシップ
- 課題解決能力
- カルチャーフィット

### 5-5. 最終面接

**【面接官】**
- 代表取締役社長又は取締役副社長

**【所要時間】**
- 30分

**【評価項目】**
- 経営理念への共感
- 入社意欲
- 将来性

### 5-6. リファレンスチェック(中途・重要ポジションのみ)
前職の上司等に、候補者の勤務状況を確認する。
※本人の同意を得て実施

## 第6章 内定・オファー

### 6-1. 内定通知

**【新卒】**
- 内々定通知: 最終面接の1週間以内
- 内定通知: 10月1日(内定式)

**【中途】**
- 内定通知: 最終面接の3営業日以内

### 6-2. オファー面談(中途)
人事部が内定者と面談し、次の条件を提示・交渉する。
- 給与
- 役職
- 入社日
- その他条件

### 6-3. 内定承諾書の提出
内定通知後、2週間以内に「内定承諾書」を提出してもらう。

### 6-4. 内定辞退への対応
内定辞退があった場合は、理由をヒアリングし、採用活動の改善に活かす。

---

## 第7章 内定者フォロー(新卒)

### 7-1. 内定式(10月)
- 内定証書授与
- 社長挨拶
- 懇親会

### 7-2. 内定者懇親会
入社までに2~3回、懇親会を実施し、内定者同士の交流を図る。

### 7-3. 内定者研修
入社前に、次の研修を実施する。
- ビジネスマナー研修(1日)
- 会社・事業理解研修(半日)
- eラーニング(自宅学習)

### 7-4. 課題図書
内定者に課題図書を配布し、読書レポートを提出してもらう。

### 7-5. 内定者面談
入社前に個別面談を実施し、不安の解消、配属先の希望確認を行う。

---

## 第8章 入社手続き

### 8-1. 入社書類の準備
入社1ヶ月前に、次の書類を提出してもらう。
1. 身元保証書
2. 卒業証明書(新卒)又は源泉徴収票(中途)
3. 年金手帳のコピー
4. 雇用保険被保険者証(中途)
5. マイナンバー
6. 通勤経路届
7. 銀行口座届
8. 健康診断書(3ヶ月以内)

### 8-2. 入社日の準備
- 社員証の作成
- PCのセットアップ
- デスク・備品の準備
- 配属先への連絡

---

## 第9章 新入社員研修

### 9-1. 新入社員研修(新卒)
入社後、3ヶ月間の研修を実施する。

**【1ヶ月目: 導入研修】**
- 会社概要、経営理念
- ビジネスマナー
- ITリテラシー
- コンプライアンス
- 各部署のローテーション研修

**【2~3ヶ月目: 配属先OJT】**
- 実務を通じた教育
- メンター制度(先輩社員がサポート)

### 9-2. 中途社員オリエンテーション
入社日に、半日のオリエンテーションを実施する。
- 会社概要、経営理念
- 社内システムの使い方
- 社内ルール
- 配属先の紹介

---

## 第10章 採用の評価・改善

### 10-1. 採用KPI
次の指標で採用活動を評価する。

| KPI | 目標値 |
|---|---|
| 採用充足率 | 100% |
| 内定承諾率 | 80%以上 |
| 採用コスト(1人あたり) | 50万円以下 |
| 入社3年後定着率 | 80%以上 |
| 採用満足度(現場) | 4.0以上(5点満点) |

### 10-2. 振り返り
採用活動終了後、次の点を振り返り、改善策を検討する。
1. 母集団形成は十分だったか
2. 選考フローは適切だったか
3. 辞退理由は何か
4. 採用した人材は活躍しているか

---

## 第11章 採用における注意事項

### 11-1. 法令遵守
採用選考にあたり、次の事項に留意する。
1. 本籍地、出生地を聞かない
2. 家族構成、家族の職業を聞かない(配偶者の有無、扶養家族数は可)
3. 思想・信条を聞かない
4. 性別、年齢による差別をしない

### 11-2. 個人情報の保護
応募者の個人情報は適切に管理し、採用目的以外に使用しない。
