# 人事評価マニュアル

**制定日**: 2024年4月1日
**最終改定**: 2025年4月1日
**管理部門**: 人事部

---

## 第1章 人事評価の目的

### 1-1. 目的
人事評価制度の目的は、次のとおりとする。
1. **公正な処遇の実現**: 成果・能力に応じた公正な昇給・昇格・賞与の決定
2. **社員の成長支援**: 目標設定とフィードバックを通じた能力開発
3. **組織目標の達成**: 会社目標と個人目標の連動
4. **コミュニケーションの促進**: 上司と部下の対話の機会創出

### 1-2. 評価対象者
正社員全員(試用期間中の社員を除く)

---

## 第2章 評価の仕組み

### 2-1. 評価期間
年2回の評価を実施する。
- **上期評価**: 4月~9月(10月に評価面談)
- **下期評価**: 10月~3月(4月に評価面談)

### 2-2. 評価の種類
評価は、次の2つの観点で行う。

**【1. 業績評価(60%)】**
- 目標の達成度を評価
- MBO(目標管理制度)により実施

**【2. 能力・行動評価(40%)】**
- 職務遂行能力、行動特性を評価
- コンピテンシー評価により実施

### 2-3. 評価者
- **一次評価者**: 直属の上司(課長・部長等)
- **二次評価者**: 一次評価者の上司(部長・本部長等)
- **最終承認**: 人事部長、担当役員

---

## 第3章 業績評価(MBO)

### 3-1. 目標設定のフロー

```
【期初(4月・10月)】
STEP1: 会社目標・部門目標の発表
↓
STEP2: 個人目標の設定(本人が起案)
↓
STEP3: 上司との面談・すり合わせ
↓
STEP4: 目標の確定・システム登録
```

### 3-2. 目標設定の原則(SMART)
目標は、次の5つの要素を満たすこと。

- **S**pecific: 具体的である
- **M**easurable: 測定可能である
- **A**chievable: 達成可能である
- **R**elevant: 組織目標と関連している
- **T**ime-bound: 期限が明確である

### 3-3. 目標の数
1人あたり3~5個の目標を設定する。

### 3-4. 目標の分類と配分

| 分類 | 内容 | 配分 |
|---|---|---|
| 業績目標 | 売上、利益、品質等の数値目標 | 50% |
| 業務改善目標 | プロセス改善、効率化等 | 30% |
| 能力開発目標 | スキルアップ、資格取得等 | 20% |

### 3-5. 目標設定の例

**【営業職の目標例】**
1. 売上目標5,000万円を達成する(達成率100%以上)
2. 新規顧客を10社開拓する
3. 顧客満足度調査でNPS +30以上を獲得する
4. 営業プロセスをCRMに100%入力し、商談の可視化を実現する
5. 営業スキル向上のため、「営業力強化研修」を受講する

**【エンジニアの目標例】**
1. 〇〇プロジェクトを予算内・納期内で完遂する(品質基準クリア)
2. バグ発生率を前期比30%削減する
3. コードレビュー指摘事項を前期比50%削減する
4. AWS認定ソリューションアーキテクトの資格を取得する
5. 新人エンジニア1名のメンター役を務め、独り立ちさせる

### 3-6. 中間レビュー
期の中間(7月・1月)に中間レビューを実施し、進捗確認と軌道修正を行う。

### 3-7. 期末評価
期末(10月・4月)に目標の達成度を自己評価し、上司が評価する。

### 3-8. 達成度の評価基準

| 評価 | 評点 | 達成度 | 説明 |
|---|---|---|---|
| S | 5点 | 120%以上 | 目標を大幅に超えて達成 |
| A | 4点 | 100~119% | 目標を達成 |
| B | 3点 | 80~99% | 概ね達成 |
| C | 2点 | 60~79% | やや未達 |
| D | 1点 | 60%未満 | 未達 |

### 3-9. 業績評価の計算

```
業績評価スコア = Σ(各目標の評点 × ウェイト) ÷ 目標数
```

**計算例**
- 目標1(ウェイト50%): 評価A(4点) → 4 × 0.5 = 2.0
- 目標2(ウェイト30%): 評価B(3点) → 3 × 0.3 = 0.9
- 目標3(ウェイト20%): 評価A(4点) → 4 × 0.2 = 0.8
- **合計: 3.7点**

## 第4章 能力・行動評価(コンピテンシー)

### 4-1. 評価項目
職種・等級に応じた評価項目を設定する。

**【全社員共通の評価項目】**
1. **チームワーク**: 周囲と協力し、チームの成果に貢献する
2. **コミュニケーション**: 円滑にコミュニケーションを図る
3. **主体性**: 自ら考え、行動する
4. **責任感**: 最後まで責任を持ってやり遂げる
5. **規律性**: ルールを守り、誠実に行動する

**【管理職の追加項目】**
6. **リーダーシップ**: チームを牽引し、成果を出す
7. **育成力**: 部下を育成する
8. **判断力**: 適切な判断を迅速に行う

### 4-2. 評価基準

| 評価 | 評点 | 説明 |
|---|---|---|
| S | 5点 | 期待を大幅に上回る行動を常に示している |
| A | 4点 | 期待通りの行動を常に示している |
| B | 3点 | 概ね期待通りの行動を示している |
| C | 2点 | 期待を下回る行動が見られる |
| D | 1点 | 期待を大きく下回る行動が多い |

### 4-3. 能力評価の計算

```
能力評価スコア = Σ(各項目の評点) ÷ 項目数
```

## 第5章 総合評価

### 5-1. 総合評価の計算

```
総合評価 = 業績評価(60%) + 能力評価(40%)
```

**計算例**
- 業績評価: 3.7点 × 0.6 = 2.22
- 能力評価: 4.0点 × 0.4 = 1.60
- **総合評価: 3.82点**

### 5-2. 総合評価のランク付け

| ランク | 点数 | 分布目安 | 説明 |
|---|---|---|---|
| S | 4.5点以上 | 5% | 極めて優秀 |
| A | 3.8~4.4点 | 20% | 優秀 |
| B | 3.0~3.7点 | 50% | 標準 |
| C | 2.0~2.9点 | 20% | やや課題あり |
| D | 2.0点未満 | 5% | 改善が必要 |

### 5-3. 評価分布の調整
部門ごとに評価分布が大きく偏らないよう、人事部が調整を行う。

## 第6章 評価面談

### 6-1. 評価面談の流れ

```
STEP1: 自己評価(本人が記入)
↓
STEP2: 一次評価(上司が評価)
↓
STEP3: 二次評価(上司の上司が調整)
↓
STEP4: 評価面談の実施(上司と本人)
↓
STEP5: 評価結果の通知
↓
STEP6: 次期目標の設定
```

### 6-2. 評価面談のポイント

**【上司(評価者)の心構え】**
1. 事実に基づいて評価する
2. 良い点を認め、改善点を具体的に伝える
3. 本人の意見を傾聴する
4. 次期に向けた期待を伝える
5. 成長をサポートする姿勢を示す

**【面談時間】**
1人あたり30分~1時間

**【面談場所】**
会議室等、他者に聞かれない場所

### 6-3. フィードバックの手法(SBI法)

- **S**ituation: 状況(いつ、どこで)
- **B**ehavior: 行動(何をしたか)
- **I**mpact: 影響(どんな結果になったか)

**例**
「先月のプロジェクトで(S)、君が率先してメンバーをフォローし(B)、全員が期限内に作業を完了できた(I)。素晴らしいリーダーシップだった。」

## 第7章 評価結果の活用

### 7-1. 昇給への反映
総合評価に基づき、昇給額を決定する。

| 評価 | 昇給額(目安) |
|---|---|
| S | 15,000円 |
| A | 10,000円 |
| B | 5,000円 |
| C | 0円 |
| D | 0円 |

### 7-2. 賞与への反映
総合評価に基づき、賞与の係数を決定する。

| 評価 | 係数 |
|---|---|
| S | 1.3 |
| A | 1.1 |
| B | 1.0 |
| C | 0.8 |
| D | 0.5 |

```
賞与 = 基本給 × 支給月数 × 係数
```

### 7-3. 昇格への反映
連続して高評価(S又はA)を獲得した社員を昇格候補とする。

---

## 第8章 評価者訓練

### 8-1. 評価者研修
評価者(管理職)に対し、年1回、評価者研修を実施する。

**【研修内容】**
1. 人事評価制度の目的・仕組み
2. 目標設定の方法(SMART)
3. 評価のポイント(事実に基づく評価)
4. 評価エラーの防止(ハロー効果、寛大化傾向等)
5. フィードバック面談の進め方
6. ロールプレイング

---

## 第9章 不服申立て

### 9-1. 不服申立て
評価結果に不服がある場合、人事部に不服申立てを行うことができる。

**【手順】**
1. 評価結果通知後、14日以内に「不服申立書」を人事部に提出
2. 人事部が調査
3. 必要に応じて、評価を再検討
4. 結果を通知
