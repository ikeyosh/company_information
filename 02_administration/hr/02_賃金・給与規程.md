# 賃金・給与規程

**制定日**: 2024年4月1日
**最終改定**: 2025年4月1日
**管理部門**: 人事部

---

## 第1章 総則

### 第1条(目的)
本規程は、就業規則第25条に基づき、社員の賃金、賞与、退職金等に関する事項を定めることを目的とする。

### 第2条(適用範囲)
本規程は、正社員に適用する。

---

## 第2章 賃金の構成

### 第3条(賃金の構成)
賃金は、次のものから構成する。
1. 基本給
2. 職務手当
3. 役職手当
4. 通勤手当
5. 家族手当
6. 住宅手当
7. 時間外手当
8. 休日手当
9. 深夜手当

---

## 第3章 基本給

### 第4条(基本給)
1. 基本給は、本人の職務内容、技能、勤務成績等を考慮して各人別に決定する。
2. 基本給は、月給制とする。

### 第5条(初任給)
初任給は、次の基準を参考に決定する。

| 学歴 | 初任給(目安) |
|---|---|
| 大学院卒(修士) | 250,000円 |
| 大学卒 | 230,000円 |
| 短大・専門学校卒 | 200,000円 |
| 高校卒 | 180,000円 |

※職務内容、本人の能力、前職経験等により加算・減算する

### 第6条(昇給)
1. 昇給は、原則として年1回、4月に行う。
2. 昇給額は、勤務成績、能力、会社の業績等を考慮して決定する。
3. 昇給の平均額: 5,000円~15,000円(目安)

---

## 第4章 諸手当

### 第7条(職務手当)
特定の職務に従事する社員に対し、次のとおり職務手当を支給する。

| 職務 | 手当額 |
|---|---|
| システムエンジニア | 30,000円 |
| プロジェクトリーダー | 20,000円 |
| 営業職 | 20,000円 |

### 第8条(役職手当)
役職者に対し、次のとおり役職手当を支給する。

| 役職 | 手当額 |
|---|---|
| 本部長 | 100,000円 |
| 部長 | 80,000円 |
| 次長 | 60,000円 |
| 課長 | 50,000円 |
| 係長 | 30,000円 |

### 第9条(通勤手当)
1. 通勤に要する交通費の実費を支給する。
2. 上限: 月額50,000円
3. 自家用車通勤の場合: ガソリン代相当額(距離に応じて)
4. 在宅勤務日は按分計算する

### 第10条(家族手当)
扶養家族のある社員に対し、次のとおり家族手当を支給する。

| 対象 | 手当額 |
|---|---|
| 配偶者 | 15,000円 |
| 子(第1子) | 10,000円 |
| 子(第2子以降) | 各5,000円 |
| 父母・祖父母 | 各5,000円 |

※扶養家族とは、所得税法上の扶養親族をいう

### 第11条(住宅手当)
1. 賃貸住宅に居住する社員に対し、次のとおり住宅手当を支給する。
   - 世帯主: 20,000円
   - 世帯主以外: 10,000円
2. 持ち家の場合は支給しない。
3. 社宅入居者には支給しない。

### 第12条(時間外手当)
1. 所定労働時間を超えて労働させた場合は、次の計算式により時間外手当を支給する。

```
時間外手当 = 1時間あたりの賃金 × 時間外労働時間 × 1.25
```

2. 1時間あたりの賃金の計算方法
```
1時間あたりの賃金 = (基本給 + 職務手当 + 役職手当) ÷ 月平均所定労働時間(173時間)
```

3. 月60時間を超える時間外労働には、割増率50%を適用する。

### 第13条(休日手当)
休日に労働させた場合は、次の計算式により休日手当を支給する。

```
休日手当 = 1時間あたりの賃金 × 休日労働時間 × 1.35
```

### 第14条(深夜手当)
22時から翌朝5時までの間に労働させた場合は、次の計算式により深夜手当を支給する。

```
深夜手当 = 1時間あたりの賃金 × 深夜労働時間 × 0.25
```

※時間外労働+深夜労働の場合: 1.25 + 0.25 = 1.50

## 第5章 賃金の計算・支払い

### 第15条(賃金の計算期間)
賃金は、毎月1日から末日までを計算期間とする。

### 第16条(賃金の支払日)
賃金は、計算期間の翌月25日に支給する。
支払日が休日の場合は、その前日に支給する。

### 第17条(賃金の支払方法)
賃金は、本人の指定する銀行口座に振り込む。

### 第18条(賃金からの控除)
賃金からは、次のものを控除する。
1. 源泉所得税
2. 住民税
3. 健康保険料
4. 厚生年金保険料
5. 雇用保険料
6. その他、法令に基づくもの又は労使協定に基づくもの

### 第19条(欠勤・遅刻・早退時の賃金)
1. 欠勤、遅刻、早退、私用外出した場合は、その時間分の賃金を控除する。

```
控除額 = 1時間あたりの賃金 × 欠勤等の時間
```

2. 1日あたりの賃金
```
1日あたりの賃金 = (基本給 + 諸手当) ÷ 月平均所定労働日数(21.7日)
```

## 第6章 賞与

### 第20条(賞与)
1. 賞与は、原則として年2回、次の時期に支給する。
   - 夏季賞与: 7月
   - 冬季賞与: 12月
2. 賞与の支給額は、会社の業績、本人の勤務成績等を考慮して決定する。
3. 標準支給月数: 年間4ヶ月分(夏2ヶ月、冬2ヶ月)

### 第21条(賞与の算定基礎額)
賞与の算定基礎額は、基本給とする。

### 第22条(賞与の支給要件)
賞与は、支給日に在籍する社員に支給する。
ただし、次の場合は支給しない、又は減額する。
1. 支給対象期間の出勤率が80%未満の場合: 不支給
2. 支給対象期間に休職していた場合: 減額
3. 支給対象期間に懲戒処分を受けた場合: 減額又は不支給

---

## 第7章 退職金

### 第23条(退職金)
1. 勤続3年以上の社員が退職した場合、退職金を支給する。
2. 退職金は、次の計算式により算定する。

```
退職金 = 基本給 × 勤続年数 × 支給率
```

### 第24条(支給率)
退職理由別の支給率は、次のとおりとする。

**【自己都合退職】**
| 勤続年数 | 支給率 |
|---|---|
| 3年以上5年未満 | 1.0 |
| 5年以上10年未満 | 2.0 |
| 10年以上15年未満 | 4.0 |
| 15年以上20年未満 | 6.0 |
| 20年以上25年未満 | 8.0 |
| 25年以上30年未満 | 10.0 |
| 30年以上 | 12.0 |

**【会社都合退職・定年退職】**
上記の1.2倍

### 第25条(退職金の減額・不支給)
次の場合、退職金を減額又は不支給とすることがある。
1. 懲戒解雇された場合: 不支給
2. 自己都合退職で、会社に損害を与えた場合: 減額

### 第26条(退職金の支払時期)
退職金は、退職日の翌月末日までに支払う。

---

## 第8章 給与明細

### 第27条(給与明細の交付)
毎月の給与支払時に、給与明細を交付する。

### 第28条(給与明細の記載事項)
給与明細には、次の事項を記載する。
1. 支給項目別の金額
2. 控除項目別の金額
3. 差引支給額
4. 勤怠情報(出勤日数、欠勤日数、遅刻・早退時間、時間外労働時間等)

---

## 第9章 雑則

### 第29条(規程の改廃)
本規程の改廃は、社員代表の意見を聴いて、会社が行う。

---

## 附則

本規程は、2024年4月1日から施行する。
