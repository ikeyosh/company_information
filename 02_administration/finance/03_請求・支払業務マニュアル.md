# 請求・支払業務マニュアル

**制定日**: 2024年4月1日
**管理部門**: 経理部

---

## 第1章 請求業務

### 1-1. 請求書発行フロー
```
月末締め → 請求書作成(翌月5日まで) → 郵送又はメール送付 → 入金確認 → 消込処理
```

### 1-2. 請求書の記載事項
- 請求書番号
- 請求日
- 請求先(会社名、部署名、担当者名)
- 請求金額(税込)
- 振込期限
- 振込先
- 明細(品名、数量、単価、金額)
- 発行者(当社名、住所、電話番号)
- 押印(社印)

### 1-3. 入金確認
- 毎日、銀行の入金を確認
- 入金があった取引先を消込
- 入金がない場合、期限後1週間以内に督促

---

## 第2章 支払業務

### 2-1. 支払サイト
- 月末締め、翌月末払い(標準)
- 手形払い、現金払いは原則廃止

### 2-2. 支払承認フロー
```
請求書受領 → 発注書と照合 → 支払申請 → 部長承認 → 経理部長承認 → 振込実行
```

### 2-3. 振込日
- 毎月25日、月末(2回)
- 振込手数料は当社負担

---

## 第3章 請求書・領収書の保管

- 請求書・領収書は7年間保存
- 月ごとにファイリング
- 電子帳簿保存法に基づき、電子保存も可

---

## 附則

本マニュアルは、2024年4月1日から施行する。
