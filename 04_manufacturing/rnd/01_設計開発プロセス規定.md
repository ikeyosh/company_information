# 設計開発プロセス規定

**制定日**: 2024年4月1日
**管理部門**: 研究開発・設計部

## 設計開発フロー
```
企画 → 要件定義 → 基本設計 → 詳細設計 → 試作 → 評価 → 量産設計 → 量産移行
```

## 各フェーズのアウトプット
- 企画: 企画書
- 要件定義: 要件定義書
- 基本設計: 基本設計書
- 詳細設計: 詳細設計書、図面
- 試作: 試作品
- 評価: 評価報告書
- 量産設計: 量産用図面
- 量産移行: 製造手順書

## デザインレビュー
各フェーズ完了時にデザインレビューを実施

## 附則
本規定は、2024年4月1日から施行する。
