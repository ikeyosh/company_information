# 作業標準書 (SOP: Standard Operating Procedure)

**制定日**: 2024年4月1日
**管理部門**: 製造・生産管理部

## 作業標準書の目的
- 作業の標準化
- 品質の安定化
- 作業者の教育

## 記載事項
1. 作業名
2. 適用範囲
3. 使用設備・工具
4. 作業手順(写真・図解付き)
5. 品質基準
6. 注意事項
7. 作成日、版数

## 作業手順の記載例
```
STEP1: 部品Aを治具にセット
STEP2: ボルトを4本締める(トルク: 10N・m)
STEP3: 動作確認
STEP4: 検査記録表に記入
```

## 改訂ルール
- 作業方法変更時は改訂
- 版数を更新
- 作業者に周知・教育

## 附則
本文書は、2024年4月1日から施行する。
