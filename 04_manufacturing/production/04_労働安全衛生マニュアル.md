# 労働安全衛生マニュアル

**制定日**: 2024年4月1日
**管理部門**: 製造・生産管理部

## 安全の基本
1. 整理整頓
2. 保護具の着用
3. 危険予知(KY)活動
4. ヒヤリハット報告

## 保護具
- 安全靴: 全員着用必須
- ヘルメット: 天井クレーン稼働時着用
- 保護メガネ: 研削作業時着用
- 手袋: 機械加工時着用(巻込み注意)

## 危険予知(KY)活動
作業開始前に、危険を予知し、対策を確認

## ヒヤリハット報告
ヒヤリとした、ハッとした出来事を報告し、再発防止

## 労災発生時の対応
```
STEP1: 被災者の救護(119番通報)
STEP2: 二次災害防止
STEP3: 上司に報告
STEP4: 労基署に報告(休業4日以上の場合)
STEP5: 原因究明
STEP6: 再発防止策
```

## 附則
本マニュアルは、2024年4月1日から施行する。
