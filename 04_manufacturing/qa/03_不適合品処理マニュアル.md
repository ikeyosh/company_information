# 不適合品処理マニュアル

**制定日**: 2024年4月1日
**管理部門**: 品質保証部

## 不適合品の定義
検査基準を満たさない製品

## 処理フロー
```
不適合発見 → 隔離 → 原因調査 → 処置決定 → 処置実行 → 記録
```

## 処置区分
1. 廃棄: 修理不可能
2. 修理: 修理後再検査
3. 特別採用: 軽微な不具合で使用可能と判断
4. 返品: サプライヤーに返却

## 原因分析
なぜなぜ分析(5Why)で根本原因を特定

## 再発防止
- 作業標準書の改訂
- 作業者への教育
- 設備の改善

## 附則
本マニュアルは、2024年4月1日から施行する。
