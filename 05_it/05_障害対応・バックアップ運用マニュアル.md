# 障害対応・バックアップ運用マニュアル

**制定日**: 2024年4月1日
**管理部門**: 情報システム部

## 障害レベル

| レベル | 定義 | 対応目標時間 |
|---|---|---|
| レベル1(致命的) | 全社システム停止 | 1時間以内に復旧 |
| レベル2(重大) | 一部システム停止 | 4時間以内に復旧 |
| レベル3(軽微) | 一部機能停止 | 1営業日以内に復旧 |

## 障害対応フロー
```
障害発生 → 検知・連絡 → 初動対応 → 原因調査 → 復旧作業 → 動作確認 → 報告
```

## バックアップ運用

### バックアップ対象
- ファイルサーバー
- データベース
- メールサーバー

### バックアップ頻度
- フル バックアップ: 毎週日曜 2:00
- 差分バックアップ: 毎日 2:00

### バックアップ保存先
- オンサイト: NAS
- オフサイト: クラウド(AWS S3)

### バックアップ保存期間
- 日次: 7日間
- 週次: 4週間
- 月次: 12ヶ月

### リストアテスト
四半期に1回、バックアップからのリストアテストを実施
