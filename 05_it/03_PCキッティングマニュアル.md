# PCキッティングマニュアル

**制定日**: 2024年4月1日
**管理部門**: 情報システム部

## キッティング作業の流れ

### STEP1: 事前準備
- PCの発注
- ユーザー情報の確認(氏名、所属、入社日)

### STEP2: OS初期設定
- Windows 11 Pro インストール
- 会社名設定
- コンピューター名設定(命名規則: PC-[社員番号])

### STEP3: ドメイン参加
- Active Directoryに参加

### STEP4: ソフトウェアインストール
- Microsoft 365 (Word, Excel, PowerPoint, Outlook等)
- ウイルス対策ソフト(Trend Micro)
- VPN Client
- Chrome
- Zoom
- Slack
- 業務システム(必要に応じて)

### STEP5: セキュリティ設定
- ファイアウォール有効化
- Windows Update実行
- 画面ロック設定(5分)
- BitLocker暗号化

### STEP6: 動作確認
- インターネット接続確認
- メール送受信確認
- プリンター接続確認

### STEP7: 納品
- ユーザーに貸与
- PC貸与確認書にサイン

## 附則
本マニュアルは、2024年4月1日から施行する。
