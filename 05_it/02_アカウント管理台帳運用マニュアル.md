# アカウント管理台帳運用マニュアル

**制定日**: 2024年4月1日
**管理部門**: 情報システム部

## 目的
全社のシステムアカウントを一元管理

## 管理対象
- Active Directory
- メールアカウント
- 各種業務システム(販売管理、経理、CRM等)
- クラウドサービス(AWS、Azure、Salesforce等)

## アカウント発行フロー
```
入社(異動) → 人事部から情報システム部に連絡 → アカウント発行 → ユーザーに通知
```

## アカウント削除フロー
```
退職(異動) → 人事部から情報システム部に連絡 → アカウント削除
```

## アカウント棚卸
年2回(4月、10月)、全アカウントを棚卸し、不要アカウントを削除

## アカウント管理台帳の記載項目
- 氏名
- 所属
- ユーザーID
- 発行日
- 削除日
- アクセス権限

## 附則
本マニュアルは、2024年4月1日から施行する。
