# 問い合わせ対応マニュアル

**制定日**: 2024年4月1日
**管理部門**: カスタマーサクセス部

## 対応チャネル
- 電話
- メール
- チャット
- お問い合わせフォーム

## 対応時間
- 平日 9:00~18:00
- 土日祝休み

## 対応フロー
```
問い合わせ受付 → 内容確認 → 一次回答 → エスカレーション(必要時) → 解決 → 完了報告
```

## 初回応答時間
- 電話: 即時
- メール: 24時間以内
- チャット: 5分以内

## 対応マナー
- 挨拶を忘れずに
- お客様の話を最後まで聞く
- 専門用語を避ける
- 曖昧な回答をしない

## 附則
本マニュアルは、2024年4月1日から施行する。
