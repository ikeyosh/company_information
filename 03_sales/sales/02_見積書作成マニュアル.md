# 見積書作成マニュアル

**制定日**: 2024年4月1日
**管理部門**: 営業部

## 第1章 見積書作成の基本

### 1-1. 見積書の記載事項
- 見積番号
- 見積日
- 有効期限(原則30日)
- 宛先(会社名、部署名、担当者名)
- 件名
- 金額(税込・税抜を明記)
- 明細(品名、数量、単価、金額)
- 備考(納期、支払条件、特記事項)

### 1-2. 見積番号のルール
```
EST-[年度]-[連番]
例: EST-2025-0001
```

## 第2章 価格設定

### 2-1. 標準価格
- 価格表に基づいて設定
- ボリュームディスカウント適用可

### 2-2. 値引き権限
| 値引率 | 承認者 |
|---|---|
| 5%以下 | 営業担当者 |
| 5~10% | 課長 |
| 10~20% | 部長 |
| 20%超 | 本部長又は役員 |

## 第3章 見積書の承認

### 3-1. 承認フロー
```
起案(営業担当) → 課長承認 → 顧客へ提出
```

※金額1,000万円以上は部長承認も必要

## 附則

本マニュアルは、2024年4月1日から施行する。
