# セールス・プロセス・マニュアル

**制定日**: 2024年4月1日
**管理部門**: 営業部

## 第1章 営業プロセス

### 1-1. 標準プロセス
```
リード獲得 → 商談化 → 提案 → クロージング → 受注 → フォロー
```

### 1-2. リード獲得
- Webサイトからの問い合わせ
- セミナー・展示会
- 既存顧客からの紹介
- テレアポ

### 1-3. 商談化(初回訪問)
- ヒアリング(課題、予算、決裁者、導入時期)
- 当社サービスの紹介
- 次回アポの取り付け

### 1-4. 提案
- 提案書の作成
- デモンストレーション
- 見積書の提示

### 1-5. クロージング
- 条件交渉
- 契約書の締結

### 1-6. 受注後フォロー
- 納品・検収
- アフターフォロー

## 第2章 商談管理

### 2-1. 商談ステージ
| ステージ | 説明 | 確度 |
|---|---|---|
| リード | 見込み客 | 10% |
| 初回訪問完了 | ヒアリング済 | 30% |
| 提案済 | 提案書提出済 | 50% |
| 見積提示 | 見積書提出済 | 70% |
| 最終交渉中 | クロージング中 | 90% |
| 受注 | 契約締結 | 100% |
| 失注 | 失注 | 0% |

### 2-2. 報告
- 日報: 毎日
- 週報: 毎週月曜
- 月報: 毎月5日まで

## 附則

本マニュアルは、2024年4月1日から施行する。
