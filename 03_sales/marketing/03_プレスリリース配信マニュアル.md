# プレスリリース配信マニュアル

**制定日**: 2024年4月1日
**管理部門**: マーケティング部

## 配信対象
- 新製品発表
- 業務提携
- 人事異動(役員)
- 決算発表
- その他重要ニュース

## 配信フロー
```
原稿作成 → 法務チェック → 役員承認 → 配信
```

## 配信先
- PR TIMES
- 主要メディア(日経、朝日、読売等)
- 業界専門誌

## プレスリリースの構成
1. 見出し(キャッチー)
2. サブ見出し
3. 本文(5W1H)
4. 会社概要
5. 問い合わせ先

## 附則
本マニュアルは、2024年4月1日から施行する。
