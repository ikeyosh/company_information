# 展示会出展マニュアル

**制定日**: 2024年4月1日
**管理部門**: マーケティング部

## 出展目的
- リード獲得
- ブランド認知向上
- 競合調査

## 出展フロー
```
3ヶ月前: 出展申込
2ヶ月前: ブース設計、ノベルティ発注
1ヶ月前: スタッフ確保、資料作成
当日: 設営、運営
事後: リードフォロー
```

## 必要準備
- ブースデザイン
- パンフレット
- ノベルティ
- デモ機材
- 名刺スキャナー

## 当日運営
- スタッフ配置(最低2名)
- 名刺交換
- アンケート実施

## 事後フォロー
- 獲得リードをCRMに登録
- 1週間以内にお礼メール
- 営業部門にパス

## 附則
本マニュアルは、2024年4月1日から施行する。
